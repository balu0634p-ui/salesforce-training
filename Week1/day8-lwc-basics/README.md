# Week 2 - Lightning Web Components (LWC)

## Introduction
In this week, I learned about Lightning Web Components (LWC) in Salesforce. LWC is a modern UI framework used to build fast and reusable components using HTML, JavaScript, and CSS. It helps in creating responsive and interactive applications inside Salesforce.

---

# What is LWC?

Lightning Web Components (LWC) is a component-based framework developed by Salesforce. It is used to create modern user interfaces for Salesforce applications. LWC uses standard web technologies such as:

- HTML
- JavaScript
- CSS

It provides better performance and cleaner code structure compared to older technologies.

---

# Why Salesforce Uses LWC

Salesforce uses LWC because:

- It gives faster performance
- Components are reusable
- Uses modern web standards
- Easy to maintain
- Better user experience
- Faster page loading
- Improved security

LWC helps developers create scalable and efficient applications inside Salesforce CRM.

# Frontend vs Backend Logic

## Frontend Logic
Frontend is the user interface part that users can see and interact with.

### Technologies Used:
- HTML
- CSS
- JavaScript
- LWC Components

### Examples:
- Buttons
- Forms
- Navigation
- Input fields
- Screen layouts

---

## Backend Logic
Backend handles business logic and database operations.

### Technologies Used:
- Apex
- Salesforce Database
- Validation Rules
- Flows

### Examples:
- Saving records
- Updating data
- Automation
- Business calculations
- Data validation
