1. What is Salesforce Platform?
Salesforce Platform is a cloud-based platform used to build, customize, and manage business applications. It helps companies manage customer data, sales, services, and business processes in one place.Using the Salesforce Platform, developers and businesses can create apps, automate workflows, store data, and improve customer relationships without needing complex hardware or infrastructure.
2. Explain: 
App:
An app in Salesforce is a collection of tools, tabs, and features designed for a specific business purpose.
Example:
Sales App
Service App
Apps help users access related features in one place.
Object:
An object in Salesforce is similar to a database table used to store information.
Example:
Account
Contact
Opportunity
Objects store records and data related to business activities.
Tab:
A tab is used to open and access objects, apps, or pages in Salesforce.
Example:
Accounts Tab
Contacts Tab
Tabs help users easily navigate through Salesforce data and features.
3. Difference: Configuration vs Coding
Configuration in Salesforce is done using built-in tools and settings without writing code. It is simple, faster, and mainly used for basic customization such as creating fields, workflows, validation rules, and reports. Coding, on the other hand, is done by writing programs using languages like Apex and Lightning Web Components. Coding is used for complex business logic, advanced automation, and custom application development. Configuration requires less technical knowledge, while coding requires programming skills.
